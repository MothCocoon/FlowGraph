This page collects notable extensions that build upon Flow Graph as the base plugin.

## AI Flow Graph
AI Flow plug-in is an extension to the Flow plug-in that adds support for commonly-used AI features like the Environment Query System (EQS) and Blackboards.

[GitHub: AI Flow Graph](https://github.com/MothCocoon/AIFlowGraph)

## AI Flow GameplayTags
Extension to the AI Flow plug-in, adding Blackboard support for GameplayTag and GameplayTagContainer. Requires Blackboard GameplayTags.

[GitHub: AI Flow GameplayTags](https://github.com/MothCocoon/AIFlowGameplayTags)

## Blackboard GameplayTags
Adds GameplayTag and GameplayTagContainer as Blackboard entry types.

[GitHub: Blackboard GameplayTags](https://github.com/MothCocoon/BlackboardGameplayTags)

## Flow Actors
Actor-focused runtime systems for Flow, including actor spawning, fight nodes, and teleport nodes.

[GitHub: Flow Actors](https://github.com/MothCocoon/FlowActors)

## AI Flow Actors
AI-specific extensions for the Flow Actors plug-in, like an EQS-based actor spawn record.

[GitHub: AI Flow Actors](https://github.com/MothCocoon/AIFlowActors)

## Flow Agent Toolkit
Editor tools for inspecting, validating, importing, and editing Flow graphs through the FlowAgent JSON format. Includes Flow's agent skill and shared agent knowledge base.

[GitHub: Flow Agent Toolkit](https://github.com/MothCocoon/FlowAgentToolkit)
